# textgen-io-plugin

📂 A simple plugin for oobabooga/text-generation-webui to allow uploading JSON/YAML files and preview their content.

## Features
- Upload `.json` or `.yaml` files
- Render them nicely as formatted text
- Designed for future integration with model input

## Install
Paste this repo URL into WebUI Extensions page:
```
https://github.com/YOUR_USERNAME/textgen-io-plugin
```
